# 0005. Android 10 (API 29) as minimum

**Status:** Accepted · 2026-10-13

## Context

The app should run on Android 10 and newer, unless a newer version is truly necessary.

## Decision

`minSdk = 29`. Everything essential exists in API 29:

- pending media items;
- unredacted photo location;
- foreground-service types;
- the thermal status API;
- the low-latency Wi-Fi lock;
- Wi-Fi Direct groups with an app-chosen name and passphrase;
- TLS 1.3.

`targetSdk` follows the Play requirement (36 today). Moving to 37 enables the local-network permission, which is already designed in.

## Consequences

Three features fall back on Android 10:

- change detection uses ID and date watermarks instead of MediaStore generations;
- there's no system trash, so deletion is permanent after an extra confirmation;
- the favourite flag isn't restored.

CI runs instrumented tests on API 29 and 36.
